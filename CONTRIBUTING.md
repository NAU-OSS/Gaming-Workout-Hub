# Contributing

First off, thank you for considering contributing! When contributing to this repository, please first discuss the change you wish to make via an issue.

## Community Guidelines and Expectations
Please note we have a [CODE_OF_CONDUCT.md](https://github.com/amb2893/CS386Project/blob/testHTML/CODE_OF_CONDUCT.md). Please follow it in all your interactions with the project. We expect all contributors to be respectful, welcoming, and collaborative.

## How to Report Bugs
If you find a bug, please create an issue and include:
* A clear and descriptive title.
* Exact steps to reproduce the behavior.
* What you expected to happen versus what actually happened.
* Screenshots if applicable.

## How to Propose New Features
Have an idea for a new workout type or feature? We would love to hear it! Please create an issue to propose your idea. Describe the feature in detail and explain why it would be beneficial to the community.

## Pull Request Process
To submit code changes:
1. Fork the repository and create your branch from the main branch.
2. Provide details of what was changed and why it was changed in your pull request description.
3. Ensure your code passes all testing and formatting guidelines.
4. Allow repository maintainers to review and merge your pull request.

## Code Style and Formatting Guidelines
* For frontend code, ensure your HTML is semantic and your CSS is well organized.
* Use clear, descriptive variable names in your JavaScript files.
* Keep functions small and focused on a single task.

## Testing Requirements
Before submitting a pull request, please ensure your code works by running the application locally. Click through all updated interface elements to ensure nothing is broken. If you add a new backend function, ensure it does not crash the local server.

## Documentation Standards
If you add a new feature, you must update the README file to include usage instructions for that feature. Additionally, please add clear comments to any complex blocks of code you write so future developers can understand your logic.
