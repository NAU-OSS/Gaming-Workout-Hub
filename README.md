# Gaming Workout Hub

Welcome to **Gaming Workout Hub**, the perfect balance between gaming and fitness! Our website is designed for gamers who want to stay active while playing their favorite video games. Whether you are looking for quick exercises between matches or a structured workout plan that fits your gaming routine, we have got you covered.

## Project Status and Roadmap
This project is currently in active development. Future planned features include:
* User accounts for tracking progress over time.
* Leaderboards to compete with friends.
* Integration with gaming platforms to trigger workouts automatically during queue times.

## Getting Started
These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites
1. A modern web browser
2. A code editor like Visual Studio Code
3. Node.js

### Installing
1. Download the repository as a ZIP folder from the main branch.
2. Extract the contents to your computer.
3. Open the extracted folder in your code editor.
4. Run your local server or open the index.html file in your web browser to view the site.

## Usage Guide and Examples
Once the application is open in your browser, you can immediately start using it to stay active:
1. **Setting an Alarm:** Navigate to the Custom Alarm section, enter your gaming session length, and the app will notify you when it is time to stretch or exercise.
2. **Quick Workouts:** Click the generation button between gaming matches to receive a short burst exercise like 10 pushups or 20 jumping jacks.
3. **Fitness Tracking:** Use the Body Test page to log your current fitness metrics and track improvements over time.
